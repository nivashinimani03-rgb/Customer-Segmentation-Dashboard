# Customer Segmentation Dashboard

## 📊 Project Overview

This project focuses on customer segmentation using Python and Power BI. The aim is to analyze customer behavior, income, spending, and engagement to identify meaningful customer groups.

K-Means clustering is used to segment customers based on selected characteristics, and the results are visualized through an interactive Power BI dashboard.

## 🎯 Objectives

- Segment customers into meaningful groups using K-Means clustering
- Analyze customer income and spending behavior
- Identify different customer segments and their characteristics
- Create interactive visualizations using Power BI
- Generate insights that can support data-driven business decisions

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Power BI
- K-Means Clustering

## 🔍 Project Workflow

1. Data collection and preparation
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Feature selection
5. Customer segmentation using K-Means clustering
6. Cluster analysis and evaluation
7. Dashboard development in Power BI
8. Business insights and interpretation
